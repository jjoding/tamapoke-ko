# 다마포케 한국어판 v0.31

기본 언어 설정 개선을 포함한 비공식 한국어 패치 소스 릴리즈입니다.

## 릴리즈 정보

| 항목 | 내용 |
|---|---|
| 현재 버전 | v0.31 |
| 펌웨어 표시 | `1.4-ko-v0.31` |
| 배포자 | jjoding |
| 대상 보드 | Waveshare ESP32-S3-Touch-AMOLED-1.75 |

## 이번 릴리즈 변경 사항

- 저장된 언어 설정이 없는 새 기기는 한국어로 시작
- 초기 스타팅 포켓몬 선택과 알 부화 흐름 한국어 표시
- 놀이·진화·작별·도감·상태·설정 화면의 한글 렌더링 개선
- 20px 단일 폰트 테이블과 24px 런타임 확대 구조 유지

## 최초 설치 흐름

1. [원작자 TamaPoke 설치 페이지](https://socquique.github.io/TamaPoke/web/)에서 원본 펌웨어 설치
2. 원작자 페이지에서 스프라이트 설치
3. 원본 보드 정상 작동 확인
4. 이 한국어판 펌웨어 설치
5. 기존 저장 데이터와 스프라이트를 보존하려면 전체 `Erase`는 선택하지 않음

이 배포판은 스프라이트 설치를 지원하지 않습니다. 원작자 페이지에서 먼저 설치합니다.

## 웹 배포 구성

```text
TamaPoke/web/index.html
TamaPoke/web/manifest.json
TamaPoke/web/firmware/tamapoke-ko.bin
```

이번 소스 패키지에는 컴파일 바이너리를 포함하지 않습니다. Flash Size를 16MB로 설정해 새로 빌드한 전체 이미지 `TamaPoke.ino.merged.bin`을 `tamapoke-ko.bin`으로 이름 변경해 위 폴더에 넣은 뒤 웹 배포에 사용합니다.

## 버전별 변경 이력

### v0.1 — 한국어판 기반 구축

- TamaPoke 화면 문자열의 한국어 번역 시작
- UTF-8 한국어 문자열과 bitmap 폰트 처리 구조 도입
- 기본 화면·상태 메뉴·설정 화면의 한국어 표시 기반 마련
- Arduino IDE용 한국어 포트 구성

### v0.11 — 한국어 출력 안정화

- ESP32-S3 보드 환경에 맞춘 빌드 구조 보완
- 폰트 헤더·핀 설정 파일 배치 문제 정리
- 상태 메뉴 한글 깨짐 수정
- 초기 한글 렌더러의 부팅·재부팅 안정화

### v0.12 — 화면별 타이포그래피 도입

- 라벨·본문·포켓몬 이름·제목의 폰트 크기 구분
- 상태·배틀·메달·성장·도감 화면의 한글 표시 보강
- `체력`, `파워 훈련` 등 주요 용어 정리
- 한글·영문·숫자 혼합 문자열의 폭과 기준선 개선
- 웹 설치 구조와 원작자 존중 안내 마련

### v0.2 — 놀이 페이지 개선

- 포켓볼 놀이 페이지의 점수·기록·신기록 한글 출력 수정
- 게임 종료 결과 메시지의 크기와 정렬 개선
- 놀이 화면의 UTF-8 렌더링 경로 통일

### v0.21 — 후속 화면 흐름 확장

- 진화·작별·도망 선택창의 한글 출력 및 크기 개선
- 시간 설정·소리 버튼·메달 알림 개선
- 상태 카드·도감·키보드 안내 문구 확대
- 스타팅 포켓몬 선택과 알 부화 흐름의 한글 표시 보강
- 20px 폰트 테이블과 24px 런타임 확대 구조 도입

### v0.30 — 전체 흐름 통합

- 주요 페이지와 후속 진행 흐름의 한글 렌더링 정책 통일
- 초기 시작부터 놀이·상태·도감·성장·설정까지 출력 품질 점검
- 웹 배포용 전체 플래시 이미지와 단순화된 배포 구조 정리
- 공개 배포 페이지의 한국어 안내 및 원작자 존중 문구 정비

### v0.31 — 초기 언어 설정 개선

- 저장된 언어 설정이 없는 새 기기는 한국어로 시작
- 기존 사용자가 선택한 영어 등 언어 설정은 계속 유지
- 초기 선택·알 부화 화면까지 한국어 기본 흐름으로 통일
