# 다마포케 한국어판 v0.30

TamaPoke를 위한 비공식 한국어판입니다. 원작자의 프로젝트를 존중하며,
원본 펌웨어와 스프라이트를 기반으로 화면 문구와 한국어 표시를 개선합니다.

## 릴리즈 정보

| 항목 | 내용 |
|---|---|
| 현재 버전 | v0.30 |
| 펌웨어 표시 | `1.4-ko-v0.30` |
| 배포자 | jjoding |
| 대상 보드 | Waveshare ESP32-S3-Touch-AMOLED-1.75 |
| 성격 | 비공식·비상업적 한국어 패치 |

## v0.30 변경 사항

- 놀이 페이지의 점수·기록·결과 메시지 한글 표시 안정화
- 진화·작별·도망 선택 대화상자의 한글 크기와 정렬 개선
- 시간 설정 화면의 제목·시간 단위·소리 버튼 개선
- 메달 획득 알림 배너의 제목과 설명 크기 개선
- 상태 카드·도감·키보드의 안내 문구 개선
- 초기 스타팅 포켓몬 선택 화면의 제목과 이름 한글 표시 보강
- 알 부화 흐름의 희귀도·도감 진행 문구 한글 표시 보강
- 한글·영문·숫자가 섞인 문장의 크기 균형 개선
- 20px 폰트 테이블 단일화와 24px 런타임 확대를 통한 컴파일 부담 감소

## 설치 안내

처음 설치하는 경우 다음 순서를 지켜주세요.

1. [원작자 TamaPoke 설치 페이지](https://socquique.github.io/TamaPoke/web/)에서 원본 펌웨어 설치
2. 원작자 페이지에서 스프라이트 설치
3. 원본 보드가 정상 작동하는지 확인
4. 이 한국어판 웹 페이지에서 한글 펌웨어 설치
5. 한글 펌웨어 설치 시 전체 `Erase`는 선택하지 않음

이 한국어판은 스프라이트 설치를 제공하지 않습니다. 원작자의 페이지에서
스프라이트까지 먼저 설치한 뒤 한국어 펌웨어만 적용하는 방식입니다.

## 웹 배포 파일

GitHub Pages에는 다음 파일을 배포합니다.

```text
TamaPoke/web/index.html
TamaPoke/web/manifest.json
TamaPoke/web/firmware/tamapoke-ko.bin
```

웹 페이지는 펌웨어 설치만 제공하며, Chrome 또는 Edge의 HTTPS 환경에서 사용합니다.

## 버전별 변경 이력

### v0.1 — 한국어판 기반 구축

- TamaPoke 화면 문자열의 한국어 번역 시작
- 한국어 bitmap 폰트와 UTF-8 문자열 처리 구조 도입
- 기본 화면·상태 메뉴·설정 화면의 한국어 표시 기반 마련
- Arduino IDE에서 직접 빌드할 수 있는 한국어 포트 구성

### v0.11 — 한국어 출력 안정화

- SensorLib와 ESP32-S3 보드 환경에 맞춘 빌드 구조 보완
- 한글 폰트 헤더와 핀 설정 파일 배치 문제 정리
- 상태 메뉴의 한글 깨짐 현상 수정
- 초기 한글 렌더러의 부팅·재부팅 문제를 줄이기 위한 안정화 작업

### v0.12 — 화면별 타이포그래피 도입

- 작은 라벨, 본문, 포켓몬 이름, 제목을 화면 목적에 따라 구분
- 상태·배틀·메달·성장·도감 화면의 한글 표시 보강
- `체력`, `파워 훈련` 등 주요 용어 정리
- 한글·영문·숫자 혼합 문자열의 기준선과 폭 개선
- 웹 펌웨어 배포 구조와 원작자 존중 안내 마련

### v0.2 — 놀이 페이지 한글 출력 개선

- 포켓볼 놀이 페이지의 점수·기록·신기록 문구 한글 렌더링 수정
- 게임 종료 결과 메시지의 크기와 정렬 개선
- 놀이 페이지에서도 UTF-8 한글이 기본 영문 폰트로 빠지지 않도록 보완

### v0.21 — 후속 화면 흐름 확장

- 진화·작별·도망 선택창의 한글 출력과 크기 개선
- 시간 설정·소리 버튼·메달 알림 개선
- 상태 카드·도감·키보드 안내 문구 확대
- 초기 스타팅 포켓몬 선택과 알 부화 흐름의 한글 표시 보강
- 20px 폰트 테이블과 24px 런타임 확대 구조로 컴파일 부담 감소

### v0.30 — 전체 흐름 통합

- 주요 페이지와 후속 진행 흐름의 한글 렌더링 정책 통일
- 초기 시작부터 놀이·상태·도감·성장·설정까지 출력 품질 점검
- 웹 배포용 전체 플래시 이미지와 단순화된 배포 구조 정리
- 공개 배포 페이지의 한국어 안내 및 원작자 존중 문구 정비
