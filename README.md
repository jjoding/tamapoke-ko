# 다마포케 한국어판 v0.50

원작자 TamaPoke v1.4를 기반으로 한 한국어 추가 패치 릴리즈입니다.
원작자 기능과 저장 구조를 유지하면서 한국어 이름 선택형 키보드를 추가했습니다.

## 릴리즈 정보

| 항목 | 내용 |
|---|---|
| 배포 버전 | v0.50 |
| 웹 manifest | 0.50.0 |
| 빌드 바이너리 표시 | `1.4-ko-v0.50` |
| 배포자 | jjoding |
| 대상 보드 | Waveshare ESP32-S3-Touch-AMOLED-1.75 |

## v0.50 변경 사항

- 한국어 이름 선택형 키보드 추가
- 27개 이름 후보를 5페이지로 구성
- `이전`, `다음`, `영문`, `지우기`, `확정`, `취소` 기능 추가
- 한글 선택형 키보드와 기존 영문 키보드 간 전환 지원
- 한글 이름 UTF-8 저장 및 문자 단위 삭제 처리
- 이름 저장 버퍼 확대
- 이름 후보와 키보드 기능에 필요한 한글 음절 폰트 추가
- 영문 키보드의 기존 입력 기능과 원작자판 호환성 유지
- 영문 키보드의 `한글`·`취소` 버튼을 원형 화면 안쪽으로 조정
- 저장 데이터를 보존하는 앱 영역 전용 웹 업데이트 유지

### v0.2 — 놀이 페이지 개선

- 스타팅 선택 회귀 문제 수정
- 릴리즈 패키지에서 스프라이트와 중복 README 제외

### v0.40 — 혼합 문자열 정렬 개선

- 한글·영문·숫자 혼합 문자열의 기준선과 폭 계산 개선
- 파워 훈련 결과를 `타격`으로 표시

### v0.40.2 — 저장 데이터 보존형 웹 업데이트

- 전체 merged 이미지 대신 앱 영역 전용 바이너리 사용

### v0.50 — 한국어 이름 선택형 키보드

- 원작자 영문 키보드를 유지하면서 한국어 이름 선택 기능 추가
- UTF-8 이름 저장과 취소·전환 흐름 보완

## 설치 전 반드시 확인

### 다마포케를 처음 설치하는 새 기기

1. [원작자 TamaPoke 설치 페이지](https://socquique.github.io/TamaPoke/web/)에서 원본 TamaPoke v1.4 펌웨어 설치
2. 원작자 페이지에서 스프라이트 설치
3. 원본 보드가 정상 작동하는지 확인
4. 이 페이지에서 한국어판 펌웨어 설치

새 기기에서 원작자 펌웨어를 처음 설치하는 경우에만 초기화가 허용됩니다.

### 이미 원작자판을 사용 중인 기존 기기

원작자 페이지에서 원본 펌웨어를 다시 설치하지 마세요. 원작자 펌웨어를 다시 설치하면 저장된 포켓몬이 초기화될 수 있습니다.

기존 사용자는 원작자 페이지를 건너뛰고 이 한국어판 페이지에서 앱 업데이트만 진행합니다.
설치 화면에서 전체 `Erase`는 선택하지 않습니다.

> ⚠️ 저장 데이터 주의: 브라우저에 이전 `manifest.json`이 캐시되어 Erase 동작이 다르게
> 보이면 설치를 중단하고 시크릿 창으로 다시 접속하거나 해당 GitHub Pages 사이트 데이터를
> 삭제하세요. `manifest.json`을 임의로 수정하지 마세요.

이 배포판은 스프라이트 설치를 지원하지 않습니다. 새 기기의 최초 스프라이트 설치는 원작자 페이지에서 진행합니다.

## 웹 배포 구성

```text
TamaPoke/web/index.html
TamaPoke/web/manifest.json
TamaPoke/web/firmware/tamapoke-ko.bin  ← 앱 영역 업데이트 이미지
```

웹 바이너리는 Arduino IDE의 `TamaPoke.ino.bin`이며, manifest는 이를 `0x10000` 앱 영역에만 기록합니다.
전체 merged 이미지가 아니므로 원본 v1.4의 부트로더·파티션·NVS 저장 영역을 유지합니다.
