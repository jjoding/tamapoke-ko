# 다마포케 한국어판 v0.32

파워 훈련 결과 화면과 프로젝트 배포 구조를 정리한 비공식 한국어 패치 소스 릴리즈입니다.

## 릴리즈 정보

| 항목 | 내용 |
|---|---|
| 현재 버전 | v0.32 |
| 펌웨어 표시 | `1.4-ko-v0.32` |
| 배포자 | jjoding |
| 대상 보드 | Waveshare ESP32-S3-Touch-AMOLED-1.75 |

## v0.32 변경 사항

- 파워 훈련 종료 결과의 `타` 단위 한글 출력 오류 수정
- 파워 훈련 결과의 숫자·한글 단위 크기와 정렬 개선
- 파워 훈련 시작·진행·종료 결과의 한글 렌더링 경로 통일
- 새 배포자를 위한 GitHub Pages 구조와 문서 정리
- 스프라이트와 웹 폴더의 불필요한 README를 배포 패키지에서 제외
- 컴파일 바이너리는 별도 빌드 후 추가하는 구조로 분리

## 최초 설치 흐름

1. [원작자 TamaPoke 설치 페이지](https://socquique.github.io/TamaPoke/web/)에서 원본 펌웨어 설치
2. 원작자 페이지에서 스프라이트 설치
3. 원본 보드 정상 작동 확인
4. 이 한국어판 펌웨어 설치
5. 기존 저장 데이터와 스프라이트를 보존하려면 전체 `Erase`는 선택하지 않음

이 배포판은 스프라이트 설치를 지원하지 않습니다. 원작자 페이지에서 먼저 설치합니다.

## 웹 배포 구성

```text
TamaPoke/web/index.html
TamaPoke/web/manifest.json
TamaPoke/web/firmware/tamapoke-ko.bin  ← 컴파일 후 추가
```

이번 패키지에는 컴파일 바이너리가 포함되어 있지 않습니다. Arduino IDE에서
Flash Size를 `16MB`로 설정하고 컴파일된 전체 이미지
`TamaPoke.ino.merged.bin`을 `tamapoke-ko.bin`으로 이름 변경해 위 폴더에 추가합니다.
