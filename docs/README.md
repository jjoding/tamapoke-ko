# 다마포케 한국어판 웹 설치 페이지

이 폴더는 GitHub Pages에 올릴 웹 펌웨어 설치 파일입니다.

```text
index.html
manifest.json
firmware/tamapoke-ko.bin
```

`tamapoke-ko.bin`은 전체 플래시 이미지이며 `manifest.json`에서 `0x0`으로 설치합니다. 스프라이트 파일은 이 폴더나 GitHub 저장소에 포함하지 않습니다.

처음 설치하는 사용자는 [원작자 TamaPoke 설치 페이지](https://socquique.github.io/TamaPoke/web/)에서 원본 펌웨어와 스프라이트를 먼저 설치한 뒤, 이 페이지에서 한국어 펌웨어를 `Erase 없이` 설치합니다.
